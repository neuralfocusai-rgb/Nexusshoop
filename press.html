NexusLang
The open-source programming language that speaks your mother tongue.

The story

English is the invisible gatekeeper of programming. Every keyword — if, while, return — assumes the learner already reads English fluently. For 6+ billion people on the planet, that's a wall before the first line of code.

NexusLang is an open-source programming language where the syntax exists natively in the learner's mother tongue. Write agar instead of if in Urdu, eğer in Turkish, si in Spanish. The code compiles to standard English syntax under the hood — so the learner thinks in their language but ships in the world's language.

"Programming shouldn't be an English club. It should be a human club. NexusLang is the first language designed that way from day one."

The entire project — compiler, test suite, 4 language packs, documentation — was built by a solo founder from an Android phone in Argentina using Termux, with zero funding and a cross-border partnership in Pakistan.
